# Vendor Risk Assessor 🛡️

Third-party/vendor risk assessments with continuous monitoring.

Part of the **Zion AI App Network** — Batch 65: Compliance & TrustOps AI.

## Features
- AI-scored vendor questionnaires (SIG, CAIQ) with evidence parsing
- Continuous monitoring of vendor security posture & breaches
- Inherent vs residual risk scoring and tiering
- Renewal reminders and reassessment scheduling
